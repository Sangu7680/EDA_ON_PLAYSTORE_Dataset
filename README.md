# 📱EDA On PlayStore Dataset

This project is about exploring and analyzing apps on the Google Play Store to understand:

What kind of apps are popular

How app size, category, or ratings affect downloads

Which categories have more apps

How free and paid apps perform

# 🧠 What Did ? 

Used Pandas for data cleaning

Removed missing values and duplicates

Used Matplotlib & Seaborn for cool visualizations

Analyzed app ratings, reviews, installs, price, category

# ✅ Steps to Run .ipynb File Locally

1. Clone the Repo

   git clone https://github.com/Sangu7680/EDA_ON_PLAYSTORE_Dataset.git
   
   cd EDA_ON_PLAYSTORE_Dataset

2. Install Jupyter (if not already installed)

   pip install notebook

3. Run the Notebook

   jupyter notebook
   
It’ll open a tab in your browser — just click on:

EDA_ON_PLAYSTORE_DATASET.ipynb
